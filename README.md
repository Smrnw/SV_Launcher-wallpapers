# Обои для SV Launcher

Изображения, которые [SV Launcher](https://github.com/Smrnw/SV_Launcher) загружает при источнике обоев «Облачная подборка».

Каждая папка — отдельная тема. В настройках лаунчера («Обои → Тема обоев») можно выбрать всю тему или одно изображение из неё. Пока тема не выбрана, используется папка `default`.

- Форматы: JPEG, PNG, WebP; до 25 МБ на файл, до 40 файлов в теме.
- Рекомендуемое разрешение — 3840×2160, соотношение сторон 16:9.
